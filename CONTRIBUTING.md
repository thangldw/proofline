# Contributing / Đóng góp / コントリビューション

- **English:** Open a focused change, preserve provenance, add regression tests and run `make test`, `make check` and affected web tests.
- **Tiếng Việt:** Giữ thay đổi tập trung, bảo toàn provenance, thêm regression test và chạy `make test`, `make check` cùng web test liên quan.
- **日本語:** 変更範囲を絞り、来歴を保持し、回帰テストを追加して `make test`、`make check`、関連 Web test を実行してください。
