# Decision policy schema

`v1/schema.json` is the JSON Schema (draft 2020-12) for `proofline.toml`. It is generated by `proofline policy-schema` from the same constants the loader uses, and a test checks that the committed file equals the generated one and that schema and loader accept and reject the same documents.

Editors that understand TOML schemas (for example Taplo or Even Better TOML) can use it for completion and validation:

```toml
#:schema https://raw.githubusercontent.com/thangldw/proofline/main/spec/decision-policy/v1/schema.json
version = 1
```

The loader remains the authority: a document the schema accepts but the loader rejects is a bug in this repository.
