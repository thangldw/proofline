# Proofline v2.6.0

Released: 2026-11-19

## English

### What shipped

- `proofline check-decisions --explain` prints, for each finding, why it fires, whether it blocks under the current policy and the command that fixes it.
- Directory overrides in `proofline.toml`: `overrides = [{path = "notes", fail_on = []}]` under `[decision_health]` gives a path its own blocking list; the longest matching directory wins. Overrides change the policy hash; policies without them hash exactly as before.
- `proofline export-adr --output-dir adr/` writes one numbered Markdown ADR per approved decision, including status, source line span, rationale, the quoted evidence and its citation health.
- `proofline check-code-refs <paths>` finds `proofline-decision: <id>` markers in code and exits 1 when one points at a missing, unapproved or stale decision.
- `proofline find-conflicts` lists approved decisions that share a subject but state different things, as candidates for a person to judge.
- Property tests now cover anchor resolution: untouched text is `unchanged`, inserted text never loses a quote, a duplicated quote is `ambiguous`, a removed quote is never `unchanged` or `moved`, and resolution is deterministic.

```bash
python -m pip install proofline-evidence==2.6.0
```

### Compatibility and evidence limits

No schema migration, export format, evidence package or attestation change. Overrides apply to the `check-decisions` gate; review ledger and SARIF output still list every finding. `find-conflicts` compares title words only and cannot see contradictions phrased with different vocabulary, so treat an empty result as "none found", not "none exist". `check-code-refs` trusts markers you write; it does not infer links from code. `proofline mcp` is unchanged: read-only, and it does not authenticate callers.

## Tiếng Việt

### Nội dung phát hành

- `proofline check-decisions --explain` in, cho từng finding, lý do, việc nó có chặn theo policy hiện tại không và lệnh để sửa.
- Override theo thư mục trong `proofline.toml`: `overrides = [{path = "notes", fail_on = []}]` dưới `[decision_health]` cho một đường dẫn danh sách chặn riêng; thư mục khớp dài nhất thắng. Override làm đổi policy hash; policy không có override hash y như trước.
- `proofline export-adr --output-dir adr/` ghi mỗi decision đã duyệt thành một ADR Markdown đánh số, gồm status, dải dòng source, lý do, evidence trích nguyên văn và health của trích dẫn.
- `proofline check-code-refs <paths>` tìm marker `proofline-decision: <id>` trong code và thoát mã 1 khi marker trỏ tới decision không tồn tại, chưa duyệt hoặc stale.
- `proofline find-conflicts` liệt kê decision đã duyệt cùng chủ đề nhưng nêu khác nhau, làm ứng viên để người đánh giá.
- Property test mới cho việc phân giải anchor: văn bản nguyên vẹn là `unchanged`, chèn thêm văn bản không làm mất quote, quote bị nhân đôi là `ambiguous`, quote bị xoá không bao giờ là `unchanged` hay `moved`, và kết quả tất định.

### Compatibility và giới hạn evidence

Không đổi schema, export, evidence package hay attestation. Override áp dụng cho gate `check-decisions`; review ledger và SARIF vẫn liệt kê mọi finding. `find-conflicts` chỉ so từ trong title nên không thấy mâu thuẫn diễn đạt bằng từ vựng khác; kết quả rỗng nghĩa là "không tìm thấy", không phải "không có". `check-code-refs` tin marker bạn viết; không suy luận liên kết từ code. `proofline mcp` không đổi: chỉ đọc và không xác thực caller.

## 日本語

### 出荷内容

- `proofline check-decisions --explain` は finding ごとに、発火理由、現在の policy で block するか、修正コマンドを表示します。
- `proofline.toml` の directory override: `[decision_health]` 配下の `overrides = [{path = "notes", fail_on = []}]` で path ごとに block 一覧を持てます。最長一致の directory が優先されます。Override は policy hash を変えますが、override のない policy の hash は従来と同じです。
- `proofline export-adr --output-dir adr/` は承認済み decision ごとに番号付き Markdown ADR を書き出します (status、source の行範囲、理由、引用 evidence、引用の health を含みます)。
- `proofline check-code-refs <paths>` は code 内の `proofline-decision: <id>` marker を探し、存在しない・未承認・stale の decision を指すと終了コード 1 で失敗します。
- `proofline find-conflicts` は、同じ主題で異なる内容を述べる承認済み decision を、人が判断する候補として列挙します。
- Anchor 解決の property test を追加しました: 変更のない文書は `unchanged`、挿入しても quote は失われず、quote の重複は `ambiguous`、削除された quote は `unchanged` や `moved` にならず、結果は決定的です。

### Compatibility と限界

schema、export 形式、evidence package、attestation に変更はありません。Override は `check-decisions` の gate に適用され、review ledger と SARIF は引き続き全 finding を列挙します。`find-conflicts` は title の語のみを比較するため、別の語彙で書かれた矛盾は見えません。空の結果は「見つからなかった」であり「存在しない」ではありません。`check-code-refs` は書かれた marker を信頼し、code から関係を推測しません。`proofline mcp` は変更なく、読み取り専用で caller を認証しません。
