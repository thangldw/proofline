# Proofline v2.1.0

Released: 2026-11-19

## English

### What shipped

- `proofline sync PATH [--uri-root URI]`: a headless, deterministic folder indexer. It needs no server and keeps source identity stable across machines through `--uri-root`.
- A reusable composite GitHub Action (`action.yml`) that restores a committed portable snapshot, syncs the checked-out documents, and fails a pull request when an approved decision's exact cited evidence changed. It writes a SARIF report and a job summary.
- A pull-request gate recipe in `docs/pr-gate.md`: the snapshot lives in the repository, so a team shares decisions without hosted sync, OAuth, or organization identity.

```bash
python -m pip install proofline-evidence==2.1.0
proofline sync docs --uri-root file:///path/where/decisions/were/approved/docs
proofline check-decisions
```

### Compatibility and evidence limits

Schemas, the SQLite data model, evidence packages, and signed attestations are unchanged from v2.0.2. The gate is deterministic and needs no AI provider. A snapshot committed to Git is a shared file, not a trusted record: anyone who can edit the repository can edit the snapshot, so protect the branch and review snapshot changes. Scope remains one local database per run; there is no hosted sync.

## Tiếng Việt

### Nội dung phát hành

- `proofline sync PATH [--uri-root URI]`: indexer thư mục headless, xác định, không cần server, giữ source identity ổn định giữa các máy qua `--uri-root`.

- Công thức PR gate trong `docs/pr-gate.md`: snapshot nằm trong repository nên team chia sẻ decision mà không cần hosted sync, OAuth hay organization identity.

```bash
python -m pip install proofline-evidence==2.1.0
proofline sync docs --uri-root file:///path/where/decisions/were/approved/docs
proofline check-decisions
```

### Compatibility và giới hạn evidence

Phạm vi vẫn là một database local mỗi lần chạy; chưa có hosted sync.
