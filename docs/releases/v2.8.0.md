# Proofline v2.8.0

Released: 2026-11-19

## English

### What shipped

- `proofline doctor` gives a read-only overview of a local workspace: migrations current, integrity verified, an optional policy file valid (`--policy`), reviews open longer than the policy allows, and the age of the last health snapshot. It exits 1 only when a check fails; warnings do not fail it.
- `proofline mcp` gains read-only `check_expiry` and `find_conflicts` tools. Results are content-free by default; shared conflict words are title text, so they appear only with `--include-titles`.
- The GitHub Action gains `check-expiry: "true"` (fail on decisions past `Review by:`) and `code-refs: "src docs"` (fail on `proofline-decision: <id>` markers that are missing, unapproved or stale). Each fails the step independently of the decision gate.

```bash
python -m pip install proofline-evidence==2.8.0
```

### Compatibility and evidence limits

No schema migration, export format, evidence package or attestation change; the new action inputs default to off. The action runs in an ephemeral workspace, so it cannot show a health trend; run `snapshot-health` where the database persists. `doctor` checks the local database only. `proofline mcp` is unchanged: read-only, and it does not authenticate callers.

## Tiếng Việt

### Nội dung phát hành

- `proofline doctor` cho tổng quan chỉ đọc về workspace cục bộ: migration đã mới nhất, integrity đã verify, file policy tùy chọn hợp lệ (`--policy`), review mở lâu hơn policy cho phép, và tuổi của snapshot health gần nhất. Chỉ thoát mã 1 khi một check fail; cảnh báo không làm fail.
- `proofline mcp` thêm tool chỉ đọc `check_expiry` và `find_conflicts`. Mặc định không chứa nội dung; từ chung của xung đột là văn bản title nên chỉ có với `--include-titles`.
- GitHub Action thêm `check-expiry: "true"` (fail khi decision quá hạn `Review by:`) và `code-refs: "src docs"` (fail khi marker `proofline-decision: <id>` không tồn tại, chưa duyệt hoặc stale). Mỗi cái làm step fail độc lập với gate decision.

### Compatibility và giới hạn evidence

Không đổi schema, export, evidence package hay attestation; input mới của action mặc định tắt. Action chạy trong workspace tạm nên không thể hiện xu hướng health; hãy chạy `snapshot-health` ở nơi database được giữ lại. `doctor` chỉ kiểm tra database cục bộ. `proofline mcp` không đổi: chỉ đọc và không xác thực caller.

## 日本語

### 出荷内容

- `proofline doctor` はローカル workspace の読み取り専用の概況を表示します: migration が最新か、integrity 検証、任意の policy file の妥当性 (`--policy`)、policy の許容より長く開いている review、直近の health snapshot の古さ。終了コード 1 になるのは check が失敗したときだけで、警告では失敗しません。
- `proofline mcp` に読み取り専用の `check_expiry` と `find_conflicts` tool を追加しました。既定では内容を含まず、conflict の共通語は title の文字列なので `--include-titles` のときだけ返します。
- GitHub Action に `check-expiry: "true"` (`Review by:` を過ぎた decision で失敗) と `code-refs: "src docs"` (存在しない・未承認・stale の `proofline-decision: <id>` marker で失敗) を追加しました。それぞれ decision gate とは独立して step を失敗させます。

### Compatibility と限界

schema、export 形式、evidence package、attestation に変更はなく、新しい action input は既定で無効です。Action は一時的な workspace で動くため health の推移は表示できません。database が残る場所で `snapshot-health` を実行してください。`doctor` はローカル database のみを検査します。`proofline mcp` は変更なく、読み取り専用で caller を認証しません。
