# Proofline v2.10.0

Released: 2026-11-20

## English

### What shipped

- **Decisions that bind coding agents.** The Claude Code plugin (`/plugin marketplace add thangldw/proofline`, then `/plugin install proofline@proofline`) registers `proofline agent-hook pre|post`. Before an edit the agent sees the approved decisions attached to that file, labelled as quoted repository data; after an edit, a violation of an `Enforce:` rule blocks the result with the rule so the agent can fix the code.
- **Executable decisions.** `Enforce: forbid "text" in <glob>`, `Enforce: require "text" in <glob>` and `Enforce: require file <glob>` lines are part of the cited text; `proofline check-enforcement` checks the code. Patterns are literal, never regular expressions or commands.
- **Context at the moment of change.** `proofline code-context` lists the decisions a diff touches; `proofline what-if <id>` previews the blast radius of superseding one; `proofline find-undocumented` lists added dependencies and infrastructure files no approved decision mentions; `proofline debt` ranks recently changed directories that no decision covers.
- **History.** `proofline asof <date>` reconstructs which decisions were in force at a past moment; `proofline ledger append|verify|compare` keeps a hash-chained, content-free health history in the repository and compares a pull request with its base.
- **Adoption and operations.** `import-adr`, `hook install`, `report`, `graph`, `watch`, `notify`, `completion`, `policy-schema` (with a committed JSON Schema for `proofline.toml`), and a `decision_graph` tool in the read-only MCP server.
- **Fix.** Re-syncing a document reverted to earlier content no longer fails with `ingestion_error`; the source points back at its existing version and a stale citation recovers.

```bash
python -m pip install proofline-evidence==2.10.0
```

### Compatibility and evidence limits

No schema migration, export format, evidence package or attestation change. `proofline mcp` stays read-only and does not authenticate callers; its new `decision_graph` tool withholds titles unless `--include-titles`. `Enforce:` rules are declarative and literal, and a rule is only as good as its glob. `asof` rebuilds history from source versions, timestamps and audit events, so a status changed directly in the database, or a revert made before this release, is not visible. The ledger's hash chain detects edits, not a rewrite of the whole file, and is not a signature. `find-undocumented` and `debt` are heuristics that prompt a person, not verdicts. Agent hooks put decision text in the model's context: use them only on repositories whose documents you trust. The new action inputs (`enforce`, `code-context`, `undocumented`, `ledger`) are off by default and need this version or newer.

## Tiếng Việt

### Nội dung phát hành

- **Decision ràng buộc coding agent.** Plugin Claude Code (`/plugin marketplace add thangldw/proofline`, rồi `/plugin install proofline@proofline`) đăng ký `proofline agent-hook pre|post`. Trước khi sửa, agent thấy các decision đã duyệt gắn với file đó, được gắn nhãn là dữ liệu trích từ repository; sau khi sửa, vi phạm luật `Enforce:` sẽ chặn kết quả kèm luật để agent sửa code.
- **Decision thực thi được.** Các dòng `Enforce: forbid "text" in <glob>`, `Enforce: require "text" in <glob>` và `Enforce: require file <glob>` nằm trong đoạn văn bản được trích; `proofline check-enforcement` kiểm tra code. Pattern là literal, không bao giờ là regex hay lệnh.
- **Ngữ cảnh đúng lúc thay đổi.** `proofline code-context` liệt kê decision mà một diff chạm tới; `proofline what-if <id>` xem trước phạm vi ảnh hưởng nếu thay một decision; `proofline find-undocumented` liệt kê dependency và file hạ tầng mới thêm mà không decision đã duyệt nào nhắc tới; `proofline debt` xếp hạng thư mục mới thay đổi mà không decision nào bao phủ.
- **Lịch sử.** `proofline asof <date>` dựng lại decision nào đang có hiệu lực ở một thời điểm quá khứ; `proofline ledger append|verify|compare` giữ lịch sử health nối băm, không chứa nội dung, ngay trong repository và so một pull request với nhánh gốc.
- **Áp dụng và vận hành.** `import-adr`, `hook install`, `report`, `graph`, `watch`, `notify`, `completion`, `policy-schema` (kèm JSON Schema cho `proofline.toml`) và tool `decision_graph` trong MCP server chỉ đọc.
- **Sửa lỗi.** Đồng bộ lại tài liệu đã đưa về nội dung cũ không còn fail với `ingestion_error`; source trỏ lại phiên bản đã có và citation stale phục hồi.

### Compatibility và giới hạn evidence

Không đổi schema, export, evidence package hay attestation. `proofline mcp` vẫn chỉ đọc và không xác thực caller; tool `decision_graph` mới ẩn title trừ khi có `--include-titles`. Luật `Enforce:` mang tính khai báo và literal, và chỉ tốt bằng glob của nó. `asof` dựng lại lịch sử từ source version, timestamp và audit event, nên trạng thái bị sửa thẳng trong database hoặc lần revert trước bản này không thấy được. Chuỗi băm của ledger phát hiện sửa chứ không phát hiện việc viết lại cả file, và không phải chữ ký. `find-undocumented` và `debt` là heuristic gợi ý cho con người, không phải kết luận. Agent hook đưa nội dung decision vào ngữ cảnh của model: chỉ dùng cho repository có tài liệu bạn tin cậy. Các input mới của action (`enforce`, `code-context`, `undocumented`, `ledger`) mặc định tắt và cần phiên bản này trở lên.

## 日本語

### 出荷内容

- **コーディング agent を拘束する decision。** Claude Code plugin (`/plugin marketplace add thangldw/proofline`、続けて `/plugin install proofline@proofline`) は `proofline agent-hook pre|post` を登録します。編集前に agent はそのファイルに紐づく承認済み decision を repository から引用したデータとして見ます。編集後に `Enforce:` ルールへの違反があれば、ルールとともに結果をブロックし agent が code を直せるようにします。
- **実行可能な decision。** `Enforce: forbid "text" in <glob>`、`Enforce: require "text" in <glob>`、`Enforce: require file <glob>` の行は引用される文の一部で、`proofline check-enforcement` が code を検査します。パターンはリテラルで、正規表現やコマンドではありません。
- **変更の瞬間の文脈。** `proofline code-context` は diff が触れる decision を、`proofline what-if <id>` は decision を置き換えた場合の影響範囲を、`proofline find-undocumented` は承認済み decision が言及していない追加 dependency とインフラのファイルを、`proofline debt` はどの decision も覆っていない最近変更されたディレクトリを示します。
- **履歴。** `proofline asof <date>` は過去の時点で有効だった decision を再構成し、`proofline ledger append|verify|compare` は内容を含まないハッシュ連鎖の health 履歴を repository に保持して pull request を base と比較します。
- **導入と運用。** `import-adr`、`hook install`、`report`、`graph`、`watch`、`notify`、`completion`、`policy-schema` (`proofline.toml` の JSON Schema 付き)、読み取り専用 MCP server の `decision_graph` tool。
- **修正。** 以前の内容に戻した文書の再 sync が `ingestion_error` で失敗しなくなり、source は既存の version を指し直して stale な citation が回復します。

### Compatibility と限界

schema、export 形式、evidence package、attestation に変更はありません。`proofline mcp` は読み取り専用のままで caller を認証せず、新しい `decision_graph` tool は `--include-titles` がない限り title を出しません。`Enforce:` ルールは宣言的でリテラルであり、glob の質に依存します。`asof` は source version、timestamp、audit event から履歴を再構成するため、database を直接編集した状態や本 release より前の revert は見えません。Ledger のハッシュ連鎖は編集を検出しますがファイル全体の書き換えは検出せず、署名ではありません。`find-undocumented` と `debt` は人への示唆を与える heuristic で、判定ではありません。Agent hook は decision の本文を model の文脈に入れるため、文書を信頼できる repository でのみ使ってください。新しい action input (`enforce`、`code-context`、`undocumented`、`ledger`) は既定で無効で、本 version 以降が必要です。
