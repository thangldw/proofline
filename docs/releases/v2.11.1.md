# Proofline v2.11.1

Released: 2026-11-21

## English

### What shipped

- The Claude Code plugin now lives in `plugins/proofline/` (manifest, hooks, skill, icon, README, LICENSE). `/plugin marketplace add thangldw/proofline` and `/plugin install proofline@proofline` are unchanged; the marketplace points at the new folder.
- The plugin hooks run `hooks/pre.sh` and `hooks/post.sh` through `${CLAUDE_PLUGIN_ROOT}`. They behave as before: silent unless the project has a `.proofline/proofline.db` and the `proofline` CLI is installed, and they never fail the session.
- The OpenAI plugin manifest now carries `supportURL`, which the plugin portal requires for new versions.

```bash
python -m pip install proofline-evidence==2.11.1
```

### Compatibility and evidence limits

No CLI, schema, export format, evidence package or attestation change; the Python package differs from 2.11.0 only in its version. The Claude plugin is distributed through this GitHub marketplace only: the Claude plugin directory does not accept command hooks or bundled scripts from an organization that is not verified, so Proofline is not listed there. The OpenAI plugin 2.11.0 submission is still in review and is not claimed as published. `proofline mcp` is unchanged: read-only, and it does not authenticate callers.

## Tiếng Việt

### Nội dung phát hành

- Claude Code plugin nay nằm trong `plugins/proofline/` (manifest, hook, skill, icon, README, LICENSE). `/plugin marketplace add thangldw/proofline` và `/plugin install proofline@proofline` không đổi; marketplace trỏ tới thư mục mới.
- Hook của plugin chạy `hooks/pre.sh` và `hooks/post.sh` qua `${CLAUDE_PLUGIN_ROOT}`. Hành vi như trước: im lặng trừ khi dự án có `.proofline/proofline.db` và đã cài CLI `proofline`, và không bao giờ làm hỏng phiên.
- Manifest plugin OpenAI nay có `supportURL`, mà cổng plugin yêu cầu cho version mới.

### Compatibility và giới hạn evidence

Không đổi CLI, schema, export, evidence package hay attestation; gói Python chỉ khác 2.11.0 ở số version. Claude plugin chỉ phân phối qua GitHub marketplace này: thư mục plugin của Claude không nhận hook command hay script đi kèm từ tổ chức chưa được xác minh, nên Proofline không được niêm yết ở đó. Bản nộp plugin OpenAI 2.11.0 vẫn đang được duyệt và không được tuyên bố là đã publish. `proofline mcp` không đổi: chỉ đọc và không xác thực caller.

## 日本語

### 出荷内容

- Claude Code plugin は `plugins/proofline/` (manifest、hook、skill、icon、README、LICENSE) に移動しました。`/plugin marketplace add thangldw/proofline` と `/plugin install proofline@proofline` は変わらず、marketplace は新しいフォルダを指します。
- plugin の hook は `${CLAUDE_PLUGIN_ROOT}` 経由で `hooks/pre.sh` と `hooks/post.sh` を実行します。動作は従来どおりで、プロジェクトに `.proofline/proofline.db` があり `proofline` CLI がインストールされていない限り何も出力せず、セッションを失敗させません。
- OpenAI plugin の manifest に `supportURL` を追加しました。plugin ポータルが新しい version に要求します。

### Compatibility と限界

CLI、schema、export 形式、evidence package、attestation に変更はなく、Python パッケージは 2.11.0 と version のみ異なります。Claude plugin はこの GitHub marketplace のみで配布します。Claude の plugin ディレクトリは未認証の組織による command hook や同梱 script を受け付けないため、Proofline はそこに掲載されません。OpenAI plugin 2.11.0 の提出は審査中であり、公開済みとは主張しません。`proofline mcp` は変更なく、読み取り専用で caller を認証しません。
