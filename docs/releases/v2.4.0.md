# Proofline v2.4.0

Released: 2026-11-19

## English

### What shipped

- `proofline blame <path>[:line]` answers "which approved decision is anchored here?". It lists decisions whose evidence sits in a source (matched by exact URI, path suffix, git path or title), optionally narrowed to one line of the current version, with the anchor state (`unchanged`, `moved`, `changed`, `ambiguous`, `deleted`) and the current line span. Add `--format json` for scripts.
- `proofline mcp` gains a read-only `blame_location` tool with the same lookup, so an assistant can ask why a passage reads the way it does. Results are content-free by default; decision titles appear only with `--include-titles`. `proofline mcp` remains read-only and does not authenticate callers.

```bash
python -m pip install proofline-evidence==2.4.0
```

### Compatibility and evidence limits

No schema migration, export format, evidence package or attestation change. `blame` is read-only and deterministic: it reports anchors Proofline already holds and never creates or approves a decision. Only decisions with status `active` or `accepted` are listed. A `deleted` result has no current line; it is matched against the cited line instead.

## Tiếng Việt

### Nội dung phát hành

- `proofline blame <path>[:line]` trả lời "decision đã duyệt nào đang neo ở đây?". Lệnh liệt kê decision có evidence nằm trong một source (khớp URI chính xác, đuôi đường dẫn, git path hoặc title), có thể thu hẹp theo một dòng của bản hiện tại, kèm trạng thái anchor (`unchanged`, `moved`, `changed`, `ambiguous`, `deleted`) và dải dòng hiện tại. Thêm `--format json` cho script.
- `proofline mcp` thêm tool `blame_location` chỉ đọc với cùng cách tra cứu, để trợ lý hỏi vì sao một đoạn viết như vậy. Mặc định không chứa nội dung; title decision chỉ có với `--include-titles`. `proofline mcp` vẫn chỉ đọc và không xác thực caller.

### Compatibility và giới hạn evidence

Không đổi schema, export, evidence package hay attestation. `blame` chỉ đọc và tất định: báo anchor Proofline đã có, không bao giờ tạo hay duyệt decision. Chỉ liệt kê decision có status `active` hoặc `accepted`. Kết quả `deleted` không có dòng hiện tại; nó được khớp theo dòng đã trích dẫn.

## 日本語

### 出荷内容

- `proofline blame <path>[:line]` は「ここに紐づく承認済み decision は何か」に答えます。source (URI 完全一致、path 末尾、git path、title で照合) 内に evidence を持つ decision を、現行版の 1 行に絞ることもでき、anchor 状態 (`unchanged`、`moved`、`changed`、`ambiguous`、`deleted`) と現在の行範囲とともに列挙します。script 向けに `--format json` があります。
- `proofline mcp` に同じ照会をする読み取り専用の `blame_location` tool を追加しました。既定では内容を含まず、decision title は `--include-titles` のときだけ返します。`proofline mcp` は引き続き読み取り専用で、caller を認証しません。

### Compatibility と限界

schema、export 形式、evidence package、attestation に変更はありません。`blame` は読み取り専用で決定的であり、既存の anchor を報告するだけで decision を作成・承認しません。対象は status が `active` または `accepted` の decision のみです。`deleted` には現在の行がなく、引用時の行で照合されます。
