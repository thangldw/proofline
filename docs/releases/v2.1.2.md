# Proofline v2.1.2

Released: 2026-11-19

## English

### What shipped

- Hypothesis property tests for transitive impact: on arbitrary directed graphs with cycles, the reported impact set and depths equal reverse breadth-first reachability from the reviewed root, independent of relation insertion order, and only `based_on` and `implements` edges propagate.
- A Hypothesis property for stale detection: an edit that leaves the cited quote verbatim never reports `changed` or `deleted`, and an edit to the quote always reports one of them.
- The PyPI publish verifier now retries the clean-environment install until the `/simple/` index serves the new release. Previously it read the JSON API, then installed immediately and could fail on a release that was already public.

```bash
python -m pip install proofline-evidence==2.1.2
```

### Compatibility and evidence limits

No runtime, schema, or data-model change from v2.1.1. Existing fuzz coverage of the package loader (malicious archives, oversized entries, duplicate keys) is unchanged; this release adds graph and anchor properties, not new verifier behavior.

## Tiếng Việt

### Nội dung phát hành

- Property test Hypothesis cho transitive impact: trên đồ thị có hướng bất kỳ kể cả chu trình, tập impact và depth bằng reverse breadth-first reachability từ root đang review, không phụ thuộc thứ tự chèn relation, và chỉ cạnh `based_on` cùng `implements` lan truyền.
- Property Hypothesis cho stale detection: sửa mà vẫn giữ nguyên quote được trích thì không bao giờ báo `changed` hoặc `deleted`; sửa chính quote thì luôn báo một trong hai.
- Verifier publish PyPI giờ retry bước cài trong môi trường sạch cho tới khi index `/simple/` phục vụ release mới. Trước đây script đọc JSON API rồi cài ngay nên có thể fail với release đã public.

### Compatibility và giới hạn evidence

Không đổi runtime, schema hay data model so với v2.1.1. Fuzz hiện có cho package loader (archive độc hại, entry quá lớn, key trùng) không đổi; bản này thêm property cho đồ thị và anchor, không đổi hành vi verifier.

## 日本語

### 出荷内容

- Transitive impact の Hypothesis property test: 循環を含む任意の有向グラフで、報告される impact 集合と depth は review 対象 root からの逆方向幅優先到達と一致し、relation の挿入順に依存せず、`based_on` と `implements` のみが伝播します。
- Stale detection の Hypothesis property: 引用 quote が verbatim のままなら `changed` / `deleted` は報告されず、quote 自体の編集は必ずどちらかを報告します。
- PyPI publish verifier は、`/simple/` index が新 release を返すまで clean environment への install を retry します。従来は JSON API を読んで直ちに install したため、公開済み release でも失敗し得ました。

### Compatibility と限界

v2.1.1 から runtime、schema、data model の変更はありません。Package loader の既存 fuzz (悪意ある archive、過大な entry、重複 key) は変更なしで、本 release は graph と anchor の property を追加するもので、verifier の挙動は変えません。
