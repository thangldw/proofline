# Proofline v2.0.1

Released: 2026-08-24

## English

### What shipped

- A complete English, Vietnamese, and Japanese rebuild of public, technical, policy, specification, and plugin documentation.
- Three accessible, self-contained HTML/SVG diagrams covering the local-first architecture, decision-review lifecycle, and fail-closed evidence-verification path.
- A deterministic repository contract that rejects missing language sections, broken relative links, raster documentation assets, Mermaid fences, forbidden legacy paths, and external diagram dependencies.
- Updated Python, web, desktop, CI, and plugin version surfaces for the immutable 2.0.1 release.

Install the `proofline-evidence` distribution; the executable and import package remain `proofline`:

```bash
python -m pip install proofline-evidence==2.0.1
proofline demo stale-decision
```

### Compatibility and evidence limits

This documentation-focused patch does not change the 2.0.0 runtime behavior, schemas, conformance vectors, database model, or trust boundaries. Scale figures remain synthetic qualification evidence rather than team or hosted-production benchmarks. Verify source/version alignment with `python scripts/release_check.py --tag v2.0.1`.
