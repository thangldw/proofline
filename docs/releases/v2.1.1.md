# Proofline v2.1.1

Released: 2026-11-19

## English

### What shipped

- Static type checking with mypy in `make check`. Modules that still carry pre-existing type errors are listed in a ratchet in `pyproject.toml`; every other module and every new module is checked.
- A coverage gate: `make test` fails below 88% line coverage (measured 90%).
- A `python-compat` CI job that runs the Python suite on 3.12 and 3.13 in addition to 3.11.
- Test client moved to `httpx2`, removing the Starlette deprecation warning.
- Removed a stray `workspace_id` keyword that was silently ignored when reporting unchanged folder-scan files.

```bash
python -m pip install proofline-evidence==2.1.1
```

### Compatibility and evidence limits

No runtime, schema, or data-model change from v2.1.0. The mypy ratchet is a baseline, not a claim that the whole code base is type-clean. Splitting the largest modules is deferred.

## Tiếng Việt

### Nội dung phát hành

- Kiểm tra kiểu tĩnh bằng mypy trong `make check`. Các module còn lỗi kiểu cũ nằm trong danh sách ratchet ở `pyproject.toml`; mọi module khác và module mới đều được kiểm tra.
- Cổng coverage: `make test` fail nếu dưới 88% line coverage (đo được 90%).
- Job CI `python-compat` chạy test Python trên 3.12 và 3.13, ngoài 3.11.
- Test client chuyển sang `httpx2`, bỏ cảnh báo deprecation của Starlette.
- Bỏ keyword `workspace_id` thừa bị bỏ qua âm thầm khi báo file folder-scan không đổi.

### Compatibility và giới hạn evidence

Không đổi runtime, schema hay data model so với v2.1.0. Ratchet mypy là baseline, không khẳng định toàn bộ code base sạch kiểu. Việc tách các module lớn nhất được hoãn.

## 日本語

### 出荷内容

- `make check` に mypy の静的型検査を追加。既存の型エラーを持つ module は `pyproject.toml` の ratchet に列挙し、それ以外と新規 module は検査対象です。
- Coverage gate: `make test` は line coverage 88% 未満で fail します (実測 90%)。
- Python 3.11 に加えて 3.12 / 3.13 で test を実行する `python-compat` CI job。
- Test client を `httpx2` へ移行し、Starlette の deprecation warning を解消。
- Unchanged の folder-scan file 報告時に黙って無視されていた余分な `workspace_id` keyword を削除。

### Compatibility と限界

v2.1.0 から runtime、schema、data model の変更はありません。mypy ratchet は baseline であり、code base 全体が型的に clean という主張ではありません。最大 module の分割は見送りました。
