# Proofline v2.0.0

Released: 2026-08-23

## English

### What shipped

- Deterministic, cycle-safe transitive impact over active explicit `based_on` and `implements` relations, with CLI, API, SARIF, and web projections.
- A persistent decision-review ledger with audited actions, immutable binding history, re-anchoring, resolution, and portable review receipts.
- Ed25519 attestations binding verified Decision Evidence Packages and optional verified receipts to an independently trusted public key.
- Stricter backup, import, live-integrity, package/plugin conformance, CI, and dependency-audit gates.

Install the `proofline-evidence` distribution; the CLI and import package remain `proofline`:

```bash
python -m pip install proofline-evidence==2.0.0
proofline demo stale-decision
```

### Trust and evidence limits

Impact follows only explicit active relations and reports a canonical shortest path. Review findings do not rewrite accepted decision history. Package hashes establish integrity, not authenticity. Signature verification establishes matching private-key control relative to a trusted public key, not identity, authorization, trusted time, revocation, hosted sync, or multi-user consistency.

The 10,000-decision review measurement and other scale figures are synthetic qualification evidence, not team/hosted production benchmarks. Verify source/version alignment with `python scripts/release_check.py --tag v2.0.0`.
