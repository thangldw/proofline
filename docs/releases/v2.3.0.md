# Proofline v2.3.0

Released: 2026-11-19

## English

### What shipped

- Pull-request comment: the `thangldw/proofline` action can post or update one content-free summary comment (`comment: "true"`, needs `pull-requests: write`). See `docs/pr-gate.md`.
- `proofline mcp` gains a read-only `search_evidence` tool. It returns chunk identifiers and line spans; excerpts appear only with `--include-excerpts`, titles only with `--include-titles`. The server still does not authenticate callers; `proofline mcp` remains read-only.
- `proofline verify-attestation --revocations revoked.json` rejects attestations signed by a key you list (`key_revoked`). You supply and refresh the list; Proofline distributes none.
- Folder sync is about 7x faster on large workspaces: schema migration 23 adds an index on `(workspace_id, uri)`. On 10,000 synthetic files a no-change re-sync fell from about 16.5 s to 2.2 s. `scripts/benchmark_workspace.py` reproduces the numbers.
- Internals: the type-check ratchet is gone (every module is checked by mypy), `portability.py` and `api.py` were split into smaller modules, and `cli.main` dispatches to one function per subcommand. The OpenAPI surface is unchanged.

```bash
python -m pip install proofline-evidence==2.3.0
```

### Compatibility and evidence limits

Migration 23 only creates an index; no table, column, export schema, evidence package or attestation format changes. Revocation is verifier-side: because `issued_at` is signer-chosen and there is no trusted timestamp, a revoked key is rejected whatever time it claims. RFC 3161 timestamps, hosted MCP and external connectors remain unimplemented (`docs/roadmap.md`).

## Tiếng Việt

### Nội dung phát hành

- Comment trên pull request: action `thangldw/proofline` có thể đăng hoặc cập nhật một comment tóm tắt không chứa nội dung (`comment: "true"`, cần `pull-requests: write`). Xem `docs/pr-gate.md`.
- `proofline mcp` thêm tool `search_evidence` chỉ đọc. Mặc định chỉ trả identifier và dải dòng; trích đoạn chỉ có với `--include-excerpts`, title chỉ có với `--include-titles`. Server vẫn không xác thực caller.
- `proofline verify-attestation --revocations revoked.json` từ chối attestation ký bởi khoá bạn liệt kê (`key_revoked`). Bạn tự cấp và làm mới danh sách; Proofline không phân phối danh sách nào.
- Sync thư mục nhanh hơn khoảng 7 lần trên workspace lớn: migration 23 thêm index `(workspace_id, uri)`. Với 10.000 file tổng hợp, re-sync không đổi giảm từ khoảng 16,5 s xuống 2,2 s. `scripts/benchmark_workspace.py` tái hiện số liệu.
- Nội bộ: bỏ ratchet kiểm tra kiểu (mọi module đều được mypy kiểm tra), tách `portability.py` và `api.py` thành các module nhỏ hơn, `cli.main` dispatch tới một hàm cho mỗi subcommand. Bề mặt OpenAPI không đổi.

### Compatibility và giới hạn evidence

Migration 23 chỉ tạo index; không đổi bảng, cột, export schema, evidence package hay attestation. Thu hồi khoá do verifier quyết định: vì `issued_at` do bên ký chọn và chưa có trusted timestamp nên khoá bị thu hồi bị từ chối bất kể thời điểm nó khai báo. Timestamp RFC 3161, hosted MCP và connector ngoài vẫn chưa được triển khai (`docs/roadmap.md`).

## 日本語

### 出荷内容

- Pull request comment: `thangldw/proofline` action は内容を含まない要約 comment を 1 件作成・更新できます (`comment: "true"`、`pull-requests: write` が必要)。`docs/pr-gate.md` を参照してください。
- `proofline mcp` に読み取り専用の `search_evidence` tool を追加しました。既定では identifier と行範囲のみで、抜粋は `--include-excerpts`、title は `--include-titles` のときだけ返します。Server は引き続き caller を認証しません。
- `proofline verify-attestation --revocations revoked.json` は、一覧に載る key で署名された attestation を拒否します (`key_revoked`)。一覧は利用者が用意・更新し、Proofline は配布しません。
- 大きな workspace で folder sync が約 7 倍高速になりました。Migration 23 が `(workspace_id, uri)` の index を追加します。合成 10,000 file で、変更なしの再 sync は約 16.5 秒から 2.2 秒に短縮されました。`scripts/benchmark_workspace.py` で再現できます。
- 内部: 型検査 ratchet を廃止 (全 module を mypy が検査)、`portability.py` と `api.py` を分割、`cli.main` を subcommand ごとの関数に分けました。OpenAPI は変更ありません。

### Compatibility と限界

Migration 23 は index の作成のみで、table、column、export schema、evidence package、attestation 形式は変更ありません。Revocation は verifier 側の仕組みで、`issued_at` は署名者が選ぶ値であり trusted timestamp もないため、失効 key は主張する時刻に関係なく拒否されます。RFC 3161、hosted MCP、外部 connector は未実装です (`docs/roadmap.md`)。
