# Proofline v2.2.0

Released: 2026-11-19

## English

### What shipped

- `proofline mcp`: a read-only local MCP server over stdio exposing `check_decisions`, `check_impacts`, and `list_decisions`. No network socket, no writes, no AI provider. Decision titles are withheld unless `--include-titles` is passed; citation text is never returned. See `docs/mcp.md`.
- Hypothesis fuzzing of the JSON-RPC handler: arbitrary JSON never raises, and a subprocess test drives the real stdio loop.

```bash
python -m pip install proofline-evidence==2.2.0
proofline mcp
```

### Compatibility and evidence limits

Schemas, the SQLite data model, evidence packages, and attestations are unchanged from v2.1.2. The server does not authenticate callers and is not a remote connector; hosted MCP still requires a separate security design. Existing decision-relation candidates and review overview APIs are unchanged.

## Tiếng Việt

### Nội dung phát hành

- `proofline mcp`: MCP server local chỉ đọc qua stdio, cung cấp `check_decisions`, `check_impacts` và `list_decisions`. Không network socket, không ghi, không cần AI provider. Title decision bị giữ lại trừ khi truyền `--include-titles`; citation text không bao giờ được trả về. Xem `docs/mcp.md`.

### Compatibility và giới hạn evidence

Schema, SQLite data model, evidence package và attestation không đổi so với v2.1.2. Server không xác thực caller và không phải remote connector; hosted MCP vẫn cần thiết kế bảo mật riêng. API decision-relation candidates và review overview hiện có không đổi.

## 日本語

### 出荷内容

- `proofline mcp`: stdio 経由の読み取り専用 local MCP server。`check_decisions`、`check_impacts`、`list_decisions` を提供します。Network socket、書き込み、AI provider は不要です。Decision title は `--include-titles` を指定しない限り返さず、citation text は返しません。`docs/mcp.md` を参照してください。
- JSON-RPC handler の Hypothesis fuzz: 任意の JSON で例外を出さず、subprocess test で実際の stdio loop を駆動します。

### Compatibility と限界

Schema、SQLite data model、evidence package、attestation は v2.1.2 から変更ありません。Server は caller を認証せず、remote connector でもありません。Hosted MCP には引き続き別の security 設計が必要です。既存の decision-relation candidates と review overview API は変更ありません。
