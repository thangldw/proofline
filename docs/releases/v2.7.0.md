# Proofline v2.7.0

Released: 2026-11-19

## English

### What shipped

- `proofline snapshot-health` records, per workspace, how many approved decisions exist and how many are stale (moved, changed, ambiguous, deleted). It stores counts only, never titles or text. Run it from cron or CI on a schedule.
- `proofline health-trend` shows the history as text bars, `--format json`, or a Markdown table (`--format markdown`), so you can see whether decisions are going stale faster than they are reviewed.
- Schema migration 24 adds the `decision_health_snapshots` table and an index.

```bash
python -m pip install proofline-evidence==2.7.0
```

### Compatibility and evidence limits

Migration 24 only adds a table and an index; no existing table, export schema, evidence package or attestation format changes, and snapshots are local operational data that exports do not include. Snapshots reflect the moment they were taken: a gap in the series means the command did not run, not that nothing changed. Faster first sync was measured (SQLite WAL, about 1.6x) but not applied, because it weakens power-loss durability and adds sidecar files; see `docs/roadmap.md`. `proofline mcp` is unchanged: read-only, and it does not authenticate callers.

## Tiếng Việt

### Nội dung phát hành

- `proofline snapshot-health` ghi lại, theo workspace, số decision đã duyệt và số bị stale (moved, changed, ambiguous, deleted). Chỉ lưu số đếm, không bao giờ lưu title hay văn bản. Chạy bằng cron hoặc CI theo lịch.
- `proofline health-trend` hiển thị lịch sử dưới dạng thanh văn bản, `--format json` hoặc bảng Markdown (`--format markdown`), để thấy decision có đang stale nhanh hơn tốc độ review hay không.
- Migration schema 24 thêm bảng `decision_health_snapshots` và một index.

### Compatibility và giới hạn evidence

Migration 24 chỉ thêm một bảng và một index; không đổi bảng hiện có, export schema, evidence package hay attestation, và snapshot là dữ liệu vận hành cục bộ không nằm trong export. Snapshot phản ánh thời điểm chụp: chuỗi có khoảng trống nghĩa là lệnh không chạy, không phải không có thay đổi. Sync lần đầu nhanh hơn đã được đo (SQLite WAL, khoảng 1,6 lần) nhưng chưa áp dụng vì làm yếu độ bền khi mất điện và thêm file phụ; xem `docs/roadmap.md`. `proofline mcp` không đổi: chỉ đọc và không xác thực caller.

## 日本語

### 出荷内容

- `proofline snapshot-health` は workspace ごとに、承認済み decision の数と stale (moved、changed、ambiguous、deleted) の数を記録します。保存するのは件数のみで、title や本文は保存しません。cron や CI で定期的に実行してください。
- `proofline health-trend` は履歴を文字バー、`--format json`、Markdown 表 (`--format markdown`) で表示し、decision がレビューより速く stale になっていないかを確認できます。
- Schema migration 24 が `decision_health_snapshots` table と index を追加します。

### Compatibility と限界

Migration 24 は table と index の追加のみで、既存 table、export schema、evidence package、attestation 形式は変更ありません。Snapshot はローカルの運用データで export には含まれません。Snapshot は取得時点の状態であり、系列に欠落があれば command が実行されなかったことを意味し、変更がなかったことを意味しません。初回 sync の高速化 (SQLite WAL、約 1.6 倍) は計測しましたが、停電時の耐久性を弱め sidecar file が増えるため適用していません (`docs/roadmap.md` 参照)。`proofline mcp` は変更なく、読み取り専用で caller を認証しません。
