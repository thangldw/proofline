# Proofline v1.0.0

## English

The `v1.0.0` baseline contains every feature merged into `main` as of 2026-07-26: immutable source versions, exact-span citations, deterministic stale-decision checks, Decision Evidence Package export/verification, local backup/recovery, API, web UI and desktop shell.

## Tiếng Việt

Baseline `v1.0.0` chứa toàn bộ tính năng đã merge vào `main` đến 2026-07-26: phiên bản nguồn bất biến, citation exact-span, kiểm tra quyết định lỗi thời, xuất/xác minh Decision Evidence Package, backup/khôi phục local, API, web UI và desktop shell.

## 日本語

`v1.0.0` には 2026-07-26 時点で `main` にマージ済みの全機能を含みます。不変ソース版、正確な引用範囲、古い判断の決定的検査、Decision Evidence Package の出力・検証、ローカルのバックアップ・復元、API、Web UI、デスクトップシェルです。

Status: experimental local-first software; package authenticity signatures and hosted multi-user operation are outside this release.
