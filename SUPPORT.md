# Support

## English

Use [GitHub Issues](https://github.com/thangldw/proofline/issues) for reproducible defects, setup questions, and documentation requests. Include Proofline version, operating system, exact command, sanitized output, expected result, and actual result.

Do not attach confidential sources, evidence packages, database files, credentials, private keys, or undisclosed vulnerabilities. Redact local paths and source text when they are not required to reproduce the problem. Use [GitHub Security Advisories](https://github.com/thangldw/proofline/security/advisories/new) for suspected vulnerabilities.

Support covers this repository's local single-user boundary. It does not imply a hosted service, response-time commitment, shared-workspace administration, or third-party provider support. English controls if a translation conflicts.

## Tiếng Việt

Dùng [GitHub Issues](https://github.com/thangldw/proofline/issues) cho defect có thể reproduce, câu hỏi setup và yêu cầu documentation. Gửi Proofline version, operating system, exact command, output đã sanitize, expected result và actual result.

Không đính kèm confidential source, evidence package, database file, credential, private key hoặc vulnerability chưa công bố. Redact local path và source text khi không cần để reproduce. Dùng [GitHub Security Advisories](https://github.com/thangldw/proofline/security/advisories/new) cho vulnerability nghi ngờ.

Support chỉ bao phủ local single-user boundary của repository này. Nó không ngụ ý hosted service, cam kết response time, quản trị shared workspace hoặc hỗ trợ third-party provider. English có hiệu lực nếu bản dịch xung đột.
